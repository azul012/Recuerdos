# Fotos

Pon aqui las fotos de cada mes con estos nombres:

- `mes1.jpg`
- `mes2.jpg`
- `mes3.jpg`
- `mes4.jpg`

Y asi sucesivamente hasta `mes24.jpg`.

La pagina busca automaticamente esas imagenes. Si una foto todavia no existe, muestra solo el numero del mes.

Recomendacion: usa imagenes `.jpg` livianas, idealmente de menos de 1 MB cada una.

Los textos no van en esta carpeta. Para cambiar lo que dice cada mes, abre `recuerdos.js` y edita el campo `mensaje` del mes correspondiente.
