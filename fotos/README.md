# Fotos

Pon aquí las fotos de cada mes con estos nombres:

- `mes1-1.jpg`
- `mes1-2.jpg`
- `mes1-3.jpg`
- `mes1-4.jpg`

Y así sucesivamente hasta `mes24.jpg`.

La página busca automáticamente esas imágenes. Si una foto todavía no existe, muestra solo el número del mes.

Recomendación: usa imágenes `.jpg` livianas, idealmente de menos de 1 MB cada una.

Los textos no van en esta carpeta. Para cambiar lo que dice cada mes, abre `recuerdos.js` y edita el campo `mensaje` del mes correspondiente.
